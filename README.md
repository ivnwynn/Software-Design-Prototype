A comprehensive, full-stack business management solution designed specifically for a small-scale egg reseller. EggTrack solves the critical issue of manual, error-prone inventory tracking by providing a **Mobile App** for daily offline use and a **Web Dashboard** for analytical reporting, synchronized through a centralized database.

## ✨ Features

### 📱 Mobile App (Offline-First)
* **Works Without Internet:** Records sales and stock additions using the browser's `localStorage`, ensuring the business never stops.
* **Auto-Sync:** Automatically pushes locally saved data to the database via a REST API as soon as an internet connection is detected.
* **Quick Add:** Rapidly log incoming egg trays with 1-click buttons (+12, +30, +60).
* **Sales Logging:** Deducts from current stock, calculates revenue, and prevents selling more eggs than currently available in stock.

### 💻 Web Dashboard
* **Real-Time Stock Tracking:** Fetches live data directly from the SQLite database to display current inventory.
* **Stock-in History:** Paginated view of all incoming deliveries with exact timestamps.
* **Sales Analytics:** Interactive line charts displaying revenue over time (grouped by day, week, or month) using Chart.js.
* **Data Export:** Export sales records to CSV for external reporting.
* **Dark Mode:** Fully responsive UI with a light/dark mode toggle.

## 🏗️ System Architecture

1. **The Mobile App** saves data locally to ensure zero downtime for the user.
2. An API synchronization function (`POST /api/sync`) securely sends the local data to the backend using an API Key.
3. **The Backend** safely inserts the records into the SQLite database, ignoring duplicates using unique UUIDs generated by the mobile app.
4. **The Web Dashboard** queries the backend API (`GET /api/stock`, `GET /api/sales`) to display real-time analytics and history.

## 🚀 Getting Started

### Prerequisites
* [Node.js](https://nodejs.org/) installed on your machine.
* A local web server (like the "Live Server" extension in VS Code) for the mobile app.

### 1. Backend & Dashboard Setup
Open a terminal and navigate to the `egg-dashboard` folder.

```bash
# Install dependencies
npm install
```

### 2. Mobile App Setup

1. Open the folder containing the mobile app's `index.html` in VS Code.
2. Right-click `index.html` and select **"Open with Live Server"**.
3. The app will run on `http://127.0.0.1:5500`.

<br>

> **⚠️ Important for Physical Phones:** If testing on a real phone, change the `API_URL` in the mobile `script.js` from `localhost` to your computer's local IPv4 address (e.g., `http://192.168.1.5:3000/api/sync`). Ensure your phone and PC are on the same Wi-Fi network.

## 📡 API Endpoints

The backend exposes the following REST API endpoints:

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `POST` | `/api/sync` | Receives offline data from the mobile app. *(Requires `x-api-key` header)* |
| `GET` | `/api/summary` | Returns high-level metrics (current stock, total revenue) |
| `GET` | `/api/stock` | Retrieves paginated stock-in history |
| `GET` | `/api/sales` | Retrieves paginated sales history with search and sorting |
| `GET` | `/api/revenue` | Retrieves aggregated revenue data for charts |
